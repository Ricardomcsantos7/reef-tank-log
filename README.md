# ReefTank Log

**ReefTank Log** is a web application for logging and tracking reef aquarium parameters, maintenance tasks, and observations to help hobbyists manage their tanks efficiently.

---

## Features

- Track water parameters (pH, salinity, temperature, etc.)
- Log maintenance tasks and schedules
- Add notes and observations about your aquarium
- View historical data with charts and trends
- Responsive design for desktop and mobile

---

## Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js / Supabase
- **Database:** PostgreSQL (via Supabase)
- **Version Control:** Git
